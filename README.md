# Zuhee-GW: Next-Gen Full-Stack Groupware

## Overview
Zuhee-GW is a modern groupware service built with Next.js 15 and Spring Boot 3.4.

## Project Structure
- `zuhee-gw-web`: Frontend (Next.js 15, TypeScript, Tailwind CSS)
- `zuhee-gw-api`: Backend (Spring Boot 3.4, Java 21, JPA)

## Tech Stack
- **Frontend**: Next.js 15, TypeScript, Tailwind CSS, shadcn/ui, Zustand, TanStack Query v5
- **Backend**: Spring Boot 3.4, Spring Data JPA, QueryDSL, Spring Security, PostgreSQL
- **Infrastructure**: Docker (PostgreSQL 15)
